Neutrality

Infrastructure has to be neutral, or it is not infrastructure.

The long-term goal is identity infrastructure for agent commerce, the way TLS became infrastructure for web commerce. That only works if no one owns it. So neutrality is a design constraint from day one, not a promise for later.

The pledge

No favored platforms

The verifier treats every issuer by the same rules. We do not rank, prefer, or penalize any agent platform.

No exclusive deals

Issuance is permissionless. Any builder can issue credentials under the open spec, and no deal can buy an issuer special treatment.

Verifier free, forever

Checking a credential costs nothing and always will. We monetize visibility and monitoring, never verification itself, so we never compete with the adoption we need.

Attestation, not a guarantee

We verify identity. We do not vouch for behavior. A credential that checks out means "this agent is who it claims to be," never "this agent is safe."

Why this is in writing before launch

Trust in a verifier comes from its constraints, not its claims. These four rules are the reason a merchant can rely on a yes or no from us. If we ever break one, this page and the spec are the receipt.
